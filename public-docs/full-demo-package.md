## 导入

先停止VOC服务。在安装好应用依赖的环境中，从仓库根目录执行：

```bash
python examples/import_full_demo.py
```

首次会从GitHub Releases下载完整压缩包并校验SHA-256。也可先手动下载，再运行：

```bash
python examples/import_full_demo.py --archive /path/to/voc-hotel-full-demo-v1.zip
```

随后启动应用，切换“酒店多模态演示 · 200条（虚构）”或“CXO经营演示 · 200条（虚构）”。默认工作空间及其他数据不覆盖，导入会为两个完整演示使用独立ID；重跑不覆盖已有完整空间。采集令牌会在本机重新生成。

导入使用预先完成的真实模型分析，浏览原声、图片、看板和已生成报告无需密钥，也不会触发模型计费。重新分析、新增反馈或生成新报告仍需配置自己的模型。
