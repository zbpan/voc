# 模型配置

## 两种配置方式

推荐通过侧栏“模型配置”操作；也可以在启动前设置环境变量。保存到页面的配置优先于环境变量，环境变量优先于默认值。修改环境变量后需要重启；页面保存则对后续任务生效，正在处理任务时会拒绝保存。

| 字段 | 含义 |
| --- | --- |
| API基础地址 | 兼容Chat Completions的基础路径，通常以`/v1`结尾；程序追加`/chat/completions` |
| 模型名称 | 服务商实际提供的模型ID，不是显示昵称 |
| API密钥 | 留空保留已配置值；更换地址必须重新提供密钥或勾选清除 |
| 地域备注 | 本地显示备注，不会改变API请求地域或满足数据驻留要求 |

非本机API必须使用HTTPS；本地服务可使用`http://127.0.0.1:端口/v1`。不要在地址中嵌入用户名、密码或查询参数。程序不会跟随上游HTTP重定向，避免把认证信息转发到其他地址。

当前客户端统一发送Bearer认证。对于不要求鉴权的本机模型服务，可填写一个本地占位值；它只发送给你设置的本机地址，不是服务商真实密钥。

页面提交只允许回环客户端、回环Host和同源请求，修改还要求`X-VOC-Settings`标记。开发期请先构建前端，再从8765访问配置页；不要通过Vite的5173跨源页面配置。

## 密钥存储

密钥不会在读取接口、健康检查或浏览器本地存储中回显。页面保存后，数据目录生成`model-config.json`。这是**明文配置**，不是加密保险箱；Unix系统通过受限文件权限创建，Windows使用所在目录继承的ACL，需要部署者保护目录权限。

配置写入采用临时文件及原子替换，写入失败不会切换当前服务配置。应用不会默认扫描或读取个人集中凭据目录。高级用户可显式设置`VOC_CREDENTIALS_FILE`连接自己的`dashscope`JSON配置，但此文件必须留在仓库外。

请勿上传运行目录、配置文件或密钥截图。不要将服务端口暴露到局域网或公网；当前没有用户认证。建议使用不同的`VOC_DATA_DIR`隔离测试和真实数据。

## 环境变量示例

PowerShell：

```powershell
$env:QWEN_API_KEY = '<your-key>'
$env:QWEN_BASE_URL = 'https://your-provider.example/v1'
$env:QWEN_MODEL = '<model-id>'
$env:QWEN_REGION = 'custom'
python run.py
```

macOS/Linux：

```bash
export QWEN_API_KEY='<your-key>'
export QWEN_BASE_URL='https://your-provider.example/v1'
export QWEN_MODEL='<model-id>'
python run.py
```

请在自己的终端中替换占位符，不要把真实值提交到Git。`app/.env.example`仅为字段参考，应用不自动加载`.env`。

## 兼容性与测试

文本连接测试仅发送固定短句“Reply with OK only.”，使用流式接口，不保存配置，也不发送现有反馈。它只能确认文本流式请求得到非空输出，不代表模型一定能生成合规事件JSON。

| 任务 | 服务需要支持什么 | 额外验证 |
| --- | --- | --- |
| 文字分析 | 文本消息、流式返回、按提示生成完整JSON | 转写不得改写原文，引用必须存在于原文 |
| 报告生成 | 足够上下文、流式输出和规定的JSON结构 | 引用编号必须来自快照 |
| 语音分析 | `input_audio`中接受WAV data URI | 用实际语言、时长和声道样本核对转写 |
| 图片分析 | `image_url`中接受图片data URI | 核查是否只描述可见事实，不推断不存在的投诉 |

不支持流式返回的服务需要新增适配器。模型别名可能由服务商映射成其他返回ID，应用记录上游返回型号但不把名称字符串差异直接视作错误。其他厂商和本地模型未经本项目逐一认证，不提供“一键兼容所有模型”的承诺。

保存新配置不会重跑历史记录；重试可能复用之前已经成功处理的片段。需要严格的单模型对照时，请用独立数据目录和新反馈运行。
