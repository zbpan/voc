# Changelog

## 0.1.0 — Initial open-source release

- Local voice and text feedback workspace with traceable evidence.
- Human review, follow-up history, cross-location insights, and snapshot reports.
- Local model endpoint, model ID, and API key configuration page.
- Same-origin/loopback configuration safeguards and non-disclosing secret responses.
- Original synthetic text demo, tests, and GitHub Actions workflow.
- Public distribution excludes local credentials, private keys, customer databases, research caches, and unverified media bundles.
